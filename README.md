## 📋 Overview

This repository contains a series of hands-on networking experiments designed to demonstrate fundamental concepts in computer networks using **Cisco Packet Tracer**. Each experiment focuses on specific networking protocols, configurations, and topologies.

## 📂 Project Structure

Each experiment contains a Cisco Packet Tracer (`.pkt`) file demonstrating a specific networking concept or configuration.

The repository covers fundamental topics including:

- Network areas and classifications
- Network topologies
- IPv4 and IPv6 addressing
- FTP, Telnet, HTTP, and DNS configuration
- DHCP implementation

## 🚀 Getting Started

### Prerequisites

- **Cisco Packet Tracer** (Version 7.3 or higher)
  - Download from [Cisco Networking Academy](https://www.netacad.com/courses/packet-tracer)

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/AtharvaLotankar11/Cisco---Computer-Network-Design.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Cisco---Computer-Network-Design
   ```

3. Open any `.pkt` file with Cisco Packet Tracer

## 🔍 Network Concepts Covered

This project provides practical exposure to:

- OSI and TCP/IP networking models
- LAN, MAN, and WAN architectures
- Star, Bus, Ring, Mesh, and Hybrid topologies
- Static and dynamic IP addressing
- Client-server communication
- Network services and protocols

## 📚 Learning Outcomes

After completing these experiments, you will understand:

- ✅ Different types of network areas and topologies
- ✅ IP addressing (both IPv4 and IPv6)
- ✅ Network service configuration (FTP, HTTP, DNS, DHCP)
- ✅ Remote access protocols (Telnet)
- ✅ Basic network troubleshooting
